# La liste de vérification

> Format, netteté, durée, résolution, taux d'échantillonnage, encodage — à cocher avant chaque remise.

Avant chaque remise, pour **chaque** fichier :

- [ ] **Format** : JPG, PNG ou WebP pour l'image (à la **résolution native** de la composition, **moins de 10 Mo**), MP4/WebM pour la vidéo, FLAC/Opus pour le son. Source **KRA** : moins de 100 Mo.
- [ ] **Netteté** : mise au point, pas d'artefacts visibles.
- [ ] **Durée** : dans les limites (30–60 s vidéo, 15–30 s animation, 60–90 s son, **2 min max** l'essai).
- [ ] **Résolution** : la **résolution native** de la composition pour l'image — pas de redimensionnement à l'export ; 1920×1080 à 4K pour la vidéo.
- [ ] **Taux d'échantillonnage** : 44,1/48 kHz pour le son.
- [ ] **Encodage** : débit raisonnable, niveaux sans clipping.

## Vérifier avant chaque remise

1. Le bon format d'export (ouvert), la bonne résolution, la bonne durée.
2. L'écoute/visionnement du fichier exporté de bout en bout.
3. La liste de contrôle de l'[EVS concernée](../../../../04-evaluations/sommatives/) — les critères y sont détaillés.

## D'où viennent ces critères ?

- Le détail par médium : [critères de qualité](../../../../03-savoirs/01-reconnaitre/03-criteres-qualite-fichiers/).
- Ce savoir est évalué dans **chaque** production (élément 2) et documenté au journal (élément 1) : noter les réglages d'export choisis et pourquoi.
