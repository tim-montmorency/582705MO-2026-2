# Optimiser une image

> Résolution de destination et format d'export, pour l'écran et le web.

- **Résolution de destination** : la **résolution native** de la composition — l'export ne redimensionne pas.
- **Format** : **JPG, PNG ou WebP compressé** — **moins de 10 Mo** ; le KRA (moins de 100 Mo) reste la source d'archivage
