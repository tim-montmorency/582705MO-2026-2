# La stratégie d'intégration médiatique

> Quel médium porte quoi — planifier la combinaison image, vidéo/animation et son.

- **L'image fixe** porte le sens, la précision, la composition.
- **La vidéo / l'animation** porte le mouvement, le temps, le récit.
- **Le son** porte l'émotion, l'ambiance, le rythme — souvent la moitié de l'effet.

Aucun médium n'est décoratif : chacun est choisi pour ce qu'il apporte au propos.

## Planifier

- **Réutiliser les briques** : les productions des blocs Image, Vidéo/Animation et Son deviennent le matériau de l'essai.
- **L'échéancier** : sur 3 semaines — une semaine de conceptualisation, une de production, une de finition (voir les [séances S12 à S15](../../../../01-deroulement/)).
- **La liste de ce qui manque** : une fois les briques réunies, ce qui reste à créer (captures, transitions, mixage).
