# Le visionnement collectif

> Introduire, montrer, accueillir : présenter sa création lors des remises.

- **Ce qu'on montre** : le film — rien de plus (la durée compte).
- **Ce qu'on dit** : une phrase d'introduction par équipe — l'intention, pas l'explication complète.
- **La surface de présentation** : la page de l'essai dans le [journal de bord](../../../../07-journal-de-bord/04-presentation/) porte le détail (démarche, captures, sources) — on la projette, on la partage.
- **Accueillir la rétroaction** : écouter d'abord, remercier, noter — les questions se répondent avec la page du journal sous les yeux.

## Dans le cours

- Le **visionnement collectif** (séance 15) : 21 essais enchaînés, environ 45 minutes — ponctualité, silence d'écoute, commentaires après.
- Chaque remise (S4, S9, S12, S15) est aussi un moment de présentation : visionnement ou écoute collective.
