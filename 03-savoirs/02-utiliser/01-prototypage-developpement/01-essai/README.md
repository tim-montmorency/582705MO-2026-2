# Le prototype de l'essai

> Produire tôt, exporter souvent, montrer et améliorer — appliqué à l'essai audiovisuel.

- Un **prototype** est une version préliminaire exportée — même incomplète, même avec des défauts. Il sert à voir, montrer et décider.
- Le cycle : produire → exporter → montrer → ajuster → recommencer.
- Développer par étapes : les briques des blocs précédents (image, vidéo, son) deviennent le matériau de l'essai.
- Documenter chaque étape au [journal de bord](../../../../07-journal-de-bord/) : versions successives, captures, décisions.
