# Nommer, classer, sauvegarder

> Les règles de nommage, l'arborescence de projet et les copies de secours.

## Nommer

- Les [règles d'identification du cours](../../../../00-plan-de-cours/) : `nom-de-famille_prénom_identification-du-travail_cours` — et `nom1_nom2_…` pour le travail d'équipe.
- Pas d'espaces, pas d'accents, dates en `AAAA-MM-JJ`.

## Classer

- Une **arborescence de projet** : `sources/` (rushes, matériaux), `exports/` (les versions), `projet/` (les fichiers de logiciels), `images/` (les captures).
- Des versions datées : `essai-v1-2026-11-25.mp4`, jamais de « final2 définitif ».

## Sauvegarder et archiver

- **Deux copies, deux endroits** : le dépôt Codeberg (le journal documente le projet) + un disque local ou externe.
- L'archivage = les sources + les exports : pouvoir rouvrir le projet dans un an.

## Dans le cours

- Séance [S14 — sauvegarde et archivage](../../../../01-deroulement/14/) : l'arborescence vérifiée avant la remise.
- Le journal de bord est lui-même un archivage : la mémoire du processus.
