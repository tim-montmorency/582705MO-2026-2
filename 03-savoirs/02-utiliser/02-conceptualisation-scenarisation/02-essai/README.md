# Concevoir l'essai

> L'intention, l'angle et le sujet : conceptualiser l'essai audiovisuel.

- **L'intention** : ce que vous voulez dire, pourquoi ce sujet, pour qui — un paragraphe **avant** tout logiciel.
- **L'angle** : l'essai audiovisuel est un propos personnel — pas un reportage, pas une démo technique.
- **Le sujet** : petit et précis plutôt que grand et vague ; en deux minutes, tout ce qui n'est pas essentiel est coupé.
