# Les principes de l'animation

> Les **douze principes** formulés par les animateurs de Disney (Thomas et Johnston) : le vocabulaire du mouvement animé — transposable d'un logiciel à l'autre, quelle que soit la technique.

Ces principes ne sont pas des recettes : ce sont des **outils d'observation**. On les reconnaît dans les œuvres (voir le [Corpus d'œuvres — images en mouvement](../../../../02-activites/02/animation-corpus/)), on les applique dans les exercices, on les documente au journal.
