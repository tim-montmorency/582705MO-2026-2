# Le paysage sonore

> Écouter le monde comme une **composition** : prise de son d'ambiance, description, et l'héritage de R. Murray Schafer.

## Le concept

Le **paysage sonore** (fiche <!-- start-replace-cite key="termes/paysage-sonore" -->[Paysage sonore](../../../../../05-mediagraphie/termes/paysage-sonore/ "L'environnement sonore comme composition — l'écoute du monde de Murray Schafer.")<!-- end-replace-cite -->) est l'environnement sonore d'un lieu : les sons qu'on y entend, voulus ou non. R. Murray Schafer (<!-- start-replace-cite key="livres/schafer-le-paysage-sonore-le-monde-comme-musique" -->[Le paysage sonore : le monde comme musique](../../../../../05-mediagraphie/livres/schafer-le-paysage-sonore-le-monde-comme-musique/ "L'écoute du monde comme composition — le concept de paysage sonore (soundscape), fondement du module sur le son. Édition française : Wildproject ; l'édition an…")<!-- end-replace-cite -->, <!-- start-replace-cite key="personnes/murray-schafer" -->[R. Murray Schafer](../../../../../05-mediagraphie/personnes/murray-schafer/ "Compositeur et théoricien du paysage sonore — l'écoute du monde, la soundscape composition.")<!-- end-replace-cite -->) a proposé de l'écouter comme une **composition permanente** : la ville, la classe, la forêt sont des œuvres sans début ni fin.

Adopter cette écoute transforme le créateur : on ne « prend plus du son », on **entre dans une composition**.

## En pratique

1. **Écouter** le lieu sans enregistrer : repérer les sonorités, les signaux, les rythmes.
2. **Enregistrer** une ambiance (micro placé, niveaux sains).
3. **Décrire** au journal : ce qu'on entend, ce qui domine, ce qui disparaît.
4. **Composer** : monter, mixer, faire entendre le lieu.
