# Critères de qualité — son

> Taux d'échantillonnage, format, niveaux : les critères de qualité des fichiers audio.

- **Taux d'échantillonnage** : 44,1/48 kHz (fiche <!-- start-replace-cite key="termes/echantillonnage" -->[Échantillonnage](../../../../05-mediagraphie/termes/echantillonnage/ "La numérisation du signal — fréquence et quantification, la base du son numérique.")<!-- end-replace-cite -->).
- **Format** : FLAC (sans perte, archivage), Opus (diffusion) — voir <!-- start-replace-cite key="organisations/xiph" -->[Xiph.Org Foundation](../../../../05-mediagraphie/organisations/xiph/ "La fondation des codecs libres — Vorbis, FLAC, Opus, les formats audio ouverts du Web.")<!-- end-replace-cite -->.
- **Niveaux** : crêtes, clipping, normalisation.
