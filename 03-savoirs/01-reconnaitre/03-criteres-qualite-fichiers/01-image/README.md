# Critères de qualité — image

> Format ouvert, résolution, netteté — les critères communs à tous les types d'image.

Les critères communs à toute image fixe, détaillés par type dans les
sous-dossiers :

- **Format ouvert** : PNG/SVG/PDF — jamais de format propriétaire
  (fiche <!-- start-replace-cite key="termes/format-ouvert" -->[Format ouvert](../../../../05-mediagraphie/termes/format-ouvert/ "Un format documenté publiquement, utilisable par tous sans restriction — la garantie de pérennité des projets.")<!-- end-replace-cite -->).
- **Netteté** : mise au point, pas d'artefacts visibles.
- **Lisibilité** : le contenu se lit même en niveaux de gris.
- **Source conservée** : le fichier de travail (XCF, SVG, SLA) reste
  disponible — on exporte, on ne détruit pas.
