## Les modes de fusion

Les modes de fusion sont un peu difficiles à expliquer. En gros, quand un calque est au-dessus d'un autre, l'ordinateur utilise un peu de programmation pour décider du rendu de la combinaison des deux calques.

Les modes de fusion ne s'appliquent pas qu'aux calques : ils marchent aussi sur les coups de pinceau individuels.

## Favoris

Ce sont les modes de fusion cochés comme favoris ; par défaut :

- Addition
- Brûler
- Color, HSV, HSI, HSL, HSY
- Densité de couleur
- Assombrir
- Supprimer (Effacer)
- Éclaircir
- Luminosité
- Multiplier
- Normal
- Incrustation
- Saturation HSI, HSV, HSL, HSY

## Raccourcis clavier des modes de fusion

Par défaut, les raccourcis suivants sont associés aux modes de fusion utilisés en peinture. Note : ces raccourcis **ne changent pas** le mode de fusion du calque courant.

Il faut d'abord utiliser les modificateurs `Alt + Shift`, puis la touche associée :

- `A` — Saut de ligne (Linear Burn)
- `B` — Brûler (Color Burn)
- `C` — Color, HSV, HSI, HSL, HSY
- `D` — Densité de couleur
- `E` — Différence
- `F` — Lumière douce (Photoshop) & Soft Light SVG
- `G` — Éclaircir
- `H` — Lumière dure
- `I` — Dissoudre
- `J` — Forme de ligne (Linear Light)
- `K` — Assombrir
- `L` — Mixage dur
- `M` — Multiplier
- `N` — Normal
- `O` — Incrustation
- `P` — Incrustation dure
- `Q` — Derrière
- `S` — Écran
- `T` — Saturation HSI, HSV, HSL, HSY
- `U` — Teinte HSV, HSI, HSL, HSY
- `V` — Lumière vive
- `W` — Exclusion
- `X` — Épaisseur de ligne (Linear Dodge)
- `Y` — Luminosité
- `Z` — Lumière faible
- Mode suivant : `+` · Mode précédent : `−`

## Les modes disponibles

La page officielle liste l'ensemble des modes par famille, chacune documentée : **Arithmétique** (addition, diviser, multiplier, soustraire…), **Binaire** (AND, OR, XOR…), **Assombrir** (brûler, gamma sombre, couleur plus sombre…), **HSX** (HSI, HSL, HSV, HSY), **Éclaircir** (densité de couleur, lumière dure, écran, lumière vive…), **Divers** (bumpmap, copier les canaux, dissoudre…), **Mélange** (derrière, supprimer, extraire/fusionner le grain, incrustation…), **Modulo**, **Négatif** (différence, exclusion, équivalence…), **Quadratique** (glow, heat, reflect, freeze…).
