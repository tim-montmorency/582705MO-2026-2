Le parcours de **Styxcolor**, qui a réalisé les exercices d'Animator Island **image par image dans Krita** et documenté sa progression sur Krita Artists — animations en GIF à l'appui :

- balles qui rebondissent, brique qui tombe, tête qui se tourne, personnage qui pense ;
- sac de farine : vague, saut, chute, coup de pied ;
- changement d'émotion, saut par-dessus un fossé, se lever, cycle de marche, cycle de course ;
- arbre qui tombe, personnage frappé, main qui se ferme, lever une charge, personnage qui peint, mettre son pantalon.

Ces animations illustrent plusieurs exercices du bloc Animation (voir le [TP2](../../../02-activites/02/)) — réhébergées à des fins pédagogiques, avec le **crédit de l'autrice** et le **lien vers la source**. La **licence d'utilisation n'est pas explicitement précisée** sur le fil.
