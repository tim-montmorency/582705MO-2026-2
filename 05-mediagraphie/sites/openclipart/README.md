> **CC0 / domaine public** — les cliparts peuvent être réutilisés, modifiés et intégrés sans attribution, mais évitez de reprendre un logo ou une marque existante.

Des milliers de **cliparts vectoriels** (SVG) classés par thèmes : formes, objets, personnages, icônes. Une matière première pour composer une image, un logo ou une affiche sans partir d'une page blanche.
