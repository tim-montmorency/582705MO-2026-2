# Citer un échange avec une IA
<!-- end-replace-fm -->

<!-- start-replace-fm field="description" format="blockquote" -->
> Comment déclarer et citer un échange avec un agent conversationnel (ChatGPT, Copilot, Gemini…) selon le modèle APA.
<!-- end-replace-fm -->

## Avant tout

Vérifiez auprès de votre enseignante ou de votre enseignant si l'utilisation de l'intelligence artificielle est autorisée pour le travail en question. Dans ce cours, l'usage est **permis s'il est documenté** : le journal de bord consigne l'outil, la requête et ce que vous avez modifié ensuite.

## Déclarer l'usage

Si vous avez utilisé ChatGPT ou un autre outil d'intelligence artificielle au cours de vos recherches, précisez **de quelle façon** et **dans quelles sections** de votre travail vous l'avez utilisé. Fournissez la **requête** (le *prompt*) utilisée, suivie de la partie pertinente du texte généré en réponse.

Un échange avec un outil conversationnel ne peut pas être reproduit par une autre personne qui utiliserait le même outil et la même requête : il se **cite** comme une session de discussion.

## Citation dans le texte

**Modèle** — après la citation ou la paraphrase : `(Nom de l'entité créatrice, année de la version utilisée)`.

> L'entité qui a créé l'outil conversationnel et son algorithme est considérée comme l'autrice du contenu généré. Dans le cas de ChatGPT, l'entité se nomme OpenAI.

**Exemple** — lorsque la requête « *est-ce que la division du cerveau gauche versus cerveau droit est réelle ou est-ce une métaphore ?* » est soumise à <!-- start-replace-cite key="sites/openai-chatgpt" -->[ChatGPT](../../05-mediagraphie/sites/openai-chatgpt/ "Agent conversationnel d'OpenAI — un échange n'est pas reproductible : l'entité créatrice (OpenAI) est l'autrice du contenu généré et la session doit être citée…")<!-- end-replace-cite -->, le texte généré indique que, bien que les deux hémisphères cérébraux soient quelque peu spécialisés, « la notion selon laquelle les gens peuvent être catégorisés comme “cerveau gauche logique” ou “cerveau droit créatif” est considérée comme une simplification excessive et un mythe populaire » (OpenAI, 2023).

## Bibliographie

**Modèle** :

```citation
Nom de l'entité créatrice de l'IA. (Date de la version utilisée). Nom de l'IA (version) [descriptions supplémentaires]. URL
```

**Exemple** :

```citation
OpenAI. (2023). ChatGPT (version du 30 novembre) [grand modèle de langage]. https://chat.openai.com/chat
```

**Notes** :

- **Titre** — le nom de l'agent conversationnel sert de titre. Bien qu'OpenAI nomme des itérations uniques (ChatGPT-3, ChatGPT-4), l'entreprise utilise *ChatGPT* comme nom général de l'outil.
- **Texte entre crochets** — décrit brièvement le type de modèle au lectorat (ex. « grand modèle de langage »). Les autres outils peuvent exiger des descriptions différentes.
- **Éditeur et URL** — lorsque le nom de l'éditeur diffère de l'entité créatrice, l'inscrire devant l'URL. Utiliser l'URL qui mène directement à la page où le chat peut être lancé.
