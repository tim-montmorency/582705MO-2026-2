## Activités en classe

1. **Remise EVS 1** (avant le cours) : dépôt des fichiers selon les [règles d'identification](../../00-plan-de-cours/).
2. **Visionnement collectif** (60 min) : on regarde les projets ensemble — le professeur ouvre l'image de chaque personne, commente, échange rapide. On apprend ensemble, en partageant.
3. Rétroaction croisée (15 min).
4. **Amorce du bloc vidéo** (45 min) : visionnement de références + discussion sur le langage cinématographique.
