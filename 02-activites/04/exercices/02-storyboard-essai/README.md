# Exercice — Storyboard de l'essai

> **Concept** : Découper les deux minutes : chaque plan porte sa part du propos.

Storyboarder l'essai complet (10 à 15 cases) : image fixe, vidéo, animation, son — chaque case note le médium et le son.

## Déroulement

1. Suivre un tutoriel — le concept passe avant l'outil.
2. Refaire l'exercice dans **son** logiciel, sans le tutoriel sous les yeux.
3. Documenter au [journal de bord](../../../../07-journal-de-bord/) : captures, problème → solution, réglages.
