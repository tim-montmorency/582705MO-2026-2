# Exercice — Stratégie d'intégration médiatique

> **Concept** : Quel médium porte quoi : image, vidéo, son — chacun sa part.

Remplir le tableau des briques : ce que l'image fixe porte, ce que la vidéo porte, ce que le son porte — et ce qui manque encore.
