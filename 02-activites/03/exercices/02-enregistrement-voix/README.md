# Exercice — Enregistrer sa voix

> **Concept** : Le micro, le niveau et la distance : enregistrer une voix propre.

Enregistrer 30 secondes de voix (narration, doublage) : niveau sans clipping, distance constante au micro, silence autour.

**Pourquoi ?** La voix est le premier instrument du multimédia : narration, documentaire, jeu vidéo — une voix propre avant tout traitement.

- Kdenlive ou Shotcut (enregistrement, montage)
- Téléphone + transfert

## Autovalidation

- [ ] Un environnement silencieux est choisi (ventilation, frigo, rumeur coupés)
- [ ] Le niveau est réglé : les crêtes ne touchent jamais le rouge (pas de clipping)
- [ ] La distance au micro reste constante pendant tout l'enregistrement
- [ ] 30 secondes de voix propres sont enregistrées
- [ ] Écoute critique faite : souffle, plosifs, silences
- [ ] Documenté au [journal de bord](../../../../07-journal-de-bord/) : le dépôt au journal avec les réglages (niveau, distance).
