# Exercice — Mixage multipiste

> **Concept** : Voix, ambiance, musique : équilibrer les pistes.

Mixer trois pistes — une voix, une ambiance, une musique — en équilibrant les niveaux pour que la voix reste au premier plan.

**Pourquoi ?** Le mixage fait la hiérarchie : la voix domine, la musique soutient, l'ambiance habite — podcasts, films, jeux.

## Logiciels

- Kdenlive ou Shotcut (mixage : niveaux, panoramique, filtres)

## Autovalidation

- [ ] Au moins trois pistes : voix, ambiance, musique (ou effet)
- [ ] Les niveaux relatifs sont équilibrés — la voix domine clairement
- [ ] La musique cède la place à la voix (plages, atténuations)
- [ ] Le mixage est écouté sur un autre appareil (téléphone, écouteurs)
- [ ] Documenté au [journal de bord](../../../../07-journal-de-bord/) : capture de la console, choix de mixage.
