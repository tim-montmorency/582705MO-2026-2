# Exercice — Composition d'une affiche

> **Concept** : Point, ligne, plan et hiérarchie typographique : guider l'œil.

Composer une affiche 1920×1080 — ou un autre ratio, affiché et justifié au journal : un point dominant (le titre), une ligne directrice, trois plans maximum, deux familles typographiques au plus.

**Pourquoi ?** L'affiche est le format de communication par excellence : événements, films, campagnes — une seule image doit tout dire.

## Autovalidation

- [ ] Le document est créé à partir d'un gabarit 1920×1080 — ou d'un autre ratio, justifié
- [ ] Un point dominant clair — le titre se lit en premier
- [ ] Une ligne directrice guide l'œil vers l'information
- [ ] Trois plans maximum, deux familles typographiques au plus
- [ ] La hiérarchie tient en niveaux de gris (test de lisibilité)
- [ ] Documenté au [journal de bord](../../../../07-journal-de-bord/) : du croquis à la composition, problème → solution.
