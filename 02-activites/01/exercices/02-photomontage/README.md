# Exercice — Photomontage non destructif

> **Concept** : Les calques : empiler sujet, décor et réglages — chaque étape réversible.

Composer une image à partir de plusieurs sources libres (<!-- start-replace-cite key="sites/openverse" -->[Openverse — moteur d'images libres](../../../../05-mediagraphie/sites/openverse/ "Un moteur de recherche d'images et de médias sous licences Creative Commons et du domaine public — pour trouver des visuels réutilisables légalement.")<!-- end-replace-cite -->, <!-- start-replace-cite key="sites/wikimedia-commons" -->[Wikimedia Commons — médiathèque libre](../../../../05-mediagraphie/sites/wikimedia-commons/ "La médiathèque de Wikipédia — des millions de fichiers sous licence libre, de la photo au modèle 3D, réutilisables avec crédit.")<!-- end-replace-cite -->) : un sujet détouré posé sur un nouveau décor, harmonisé (lumière, ombre).

**Pourquoi ?** Le photomontage est partout : affiches de films, visuels marketing, art numérique — empiler des sources pour créer ce qui n'existe pas encore.

## Autovalidation

- [ ] Sources libres trouvées et **créditées** (lien + licence)
- [ ] Le sujet détouré est posé sur un nouveau décor — chacun sur son calque
- [ ] Au moins un réglage non destructif (masque, calque de filtre, mode de fusion) — rien n'est aplati
- [ ] Lumière et ombre harmonisées entre les sources (direction, contraste)
- [ ] Documenté au [journal de bord](../../../../07-journal-de-bord/) : captures des étapes, problème → solution.
