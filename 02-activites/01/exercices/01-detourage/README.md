# Exercice — Détourage d'un sujet

> **Concept** : La sélection et le masque : isoler un sujet de son fond, sans rien détruire.

Extraire un sujet (personnage, objet) d'une photo pour l'utiliser ailleurs. Le cœur : **sélectionner** puis **masquer** — jamais couper.

**Pourquoi ?** Le détourage est le geste de base de la retouche et du montage : affiches, e-commerce, portraits, compositing — tout commence par isoler un sujet.

## Autovalidation

- [ ] Une sélection précise du sujet est faite (outil adapté : contiguë, similaire ou à main levée)
- [ ] Le sujet est **masqué** (masque de transparence) — aucun pixel n'est effacé
- [ ] Les contours sont propres : pas de halo du fond d'origine
- [ ] Le sujet est réutilisable : calque isolé ou export PNG avec transparence
- [ ] Documenté au [journal de bord](../../../../07-journal-de-bord/) : captures avant/après, problème → solution, réglages de sélection.
