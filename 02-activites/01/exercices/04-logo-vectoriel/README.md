# Exercice — Logo vectoriel

> **Concept** : Les formes, les aplats et le texte : un logo décliné en noir, blanc et petit.

Dessiner un logo à partir de formes simples combinées (union, différence, intersection) sur un calque vectoriel Krita, puis le décliner en noir, en blanc et en petit (32 px).

**Pourquoi ?** Les logos vivent partout : cartes d'affaires, sites web, affiches 4×3, icônes d'app — le vectoriel garantit qu'ils restent nets à toutes les tailles.

## Autovalidation

- [ ] Des formes simples sont combinées par opérations booléennes (union, différence, intersection)
- [ ] Le logo reste net à toutes les tailles — test de réduction à 32 px
- [ ] Les déclinaisons sont faites : noir, blanc, inversé
- [ ] Export : PNG ou WebP des déclinaisons (le calque vectoriel reste dans le **KRA** source)
- [ ] Documenté au [journal de bord](../../../../07-journal-de-bord/) : du croquis à la forme, problème → solution.
