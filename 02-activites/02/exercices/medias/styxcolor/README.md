# Animations de Styxcolor — crédits et réutilisation

Ces GIF proviennent du fil **« A beginner's journey to Animator Island »** de **Styxcolor** sur Krita Artists :

- <https://krita-artists.org/t/a-beginners-journey-to-animator-island/70031>

Les exercices sont ceux de la liste **« 51 Great Animation Exercises to Master »** de J.K. Riki (Animator Island) :

- <https://www.animatorisland.com/51-great-animation-exercises-to-master/>

Réhébergés dans le cours *582705MO — Introduction à la création multimédia* à des fins pédagogiques, avec le **crédit de l'autrice** (**Styxcolor**) et le **lien vers la source**. La **licence d'utilisation n'est pas explicitement précisée** sur le fil : le crédit et la source sont conservés (usage pédagogique). Les animations sont réalisées **image par image dans Krita**.
