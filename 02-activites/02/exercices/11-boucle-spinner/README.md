# Exercice — La boucle de chargement

> **Concept** : La rotation en boucle : une animation courte qui tourne à l'infini.

Animer un spinner (roue de chargement) qui tourne en boucle : un exercice complet — formes, pivot, bouclage de la timeline, export.

**Pourquoi ?** Les boucles sont partout : interfaces web, jeux vidéo, motion design — une boucle parfaite passe inaperçue.

![La boucle de chargement — une rotation parfaite](medias/boucle-spinner.svg)

*Une rotation complète (360°) qui s'enchaîne sans saut : la dernière image rejoint la première.*

- Glaxnimate
- Blender

## Autovalidation

- [ ] La ou les formes sont dessinées, le pivot centré
- [ ] La rotation est animée par keyframes (360° complets)
- [ ] La boucle est parfaite : la dernière image enchaîne la première sans saut
- [ ] Export GIF ou WebM, poids raisonnable
- [ ] Documenté au [journal de bord](../../../../07-journal-de-bord/) : captures, problème → solution.
