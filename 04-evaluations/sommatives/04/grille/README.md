# Grille d'évaluation — EVS 4 : Essai audiovisuel + présentation + journal final

## Comment lire la grille

- **Élément 1 (30 % du cours)** — reconnaître : critères de qualité, évolution artistique — porté ici par la qualité de l'export, la prise de risque créative et le journal final.
- **Élément 2 (70 % du cours)** — utiliser le médium : concevoir, planifier l'intégration, exploiter les logiciels, présenter.
- Les points s'additionnent sur 100, puis se rapportent au poids de l'EVS (40 % de la note finale).
- Logistique : le film est remis à la séance 14, le visionnement collectif a lieu à la séance 15 — voir la [liste de vérification](../../../../03-savoirs/02-utiliser/08-respect-criteres-qualite/01-liste-de-verification/).
